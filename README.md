# Personal Expense & Budget Manager

A web-based personal finance management application developed using **Rust, SQLite, HTML, CSS, and JavaScript**. It helps users track their income and expenses, organize transactions, and visualize their financial activities through charts.

## 🚀 Features

- **Income Tracking:** Add and manage income transactions.
- **Expense Tracking:** Record and manage daily expenses.
- **Category Management:** Organize transactions by category.
- **Financial Summary:** View total income and expenses.
- **Data Visualization:** Display financial information through charts.
- **Transaction History:** Maintain transaction details, including amount, type, category, description, and date.
- **Database Storage:** Store transaction records using SQLite.

## 🛠️ Technologies Used

- **Rust** – Backend development
- **Axum** – Backend web framework
- **SQLite** – Database
- **SQLx** – Database connectivity
- **HTML** – Frontend structure
- **CSS** – Styling
- **JavaScript** – Frontend functionality

## ⚙️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Sanjana-Pakala/expense-budget-manager.git
```

**2. Navigate to the project directory**

```bash
cd expense-budget-manager
```

**3. Build the project**

```bash
cargo build
```

**4. Run the application**

```bash
cargo run
```

**5. Open in your browser**

```text
http://127.0.0.1:3000
```
